# Runtime deps for the 32-bit Python 3.10 sidecar (PyInstaller bundle).
#
# scipy is still excluded: it doesn't ship 32-bit Windows wheels for Python
# 3.10 (last 32-bit win wheel was scipy 1.7.x), and sampling.py lazy-imports
# it so the sidecar starts fine without it.
#
# matplotlib and python-docx ARE needed here, despite an earlier note saying
# otherwise: the report and chart-export endpoints both use them, and without
# them a packaged build answers `{"detail": "No module named 'matplotlib'"}`
# to every chart or report download while working perfectly in dev.
#
# ── Why numpy is capped below 2.0 ────────────────────────────────────────────
# Only on this 32-bit interpreter. matplotlib's last release with a win32
# wheel is 3.7.5, and matplotlib only gained numpy 2 support in 3.8.4 — so on
# 32-bit Windows there is no combination of matplotlib and numpy 2 that works.
# Installing numpy 2.x here gets you an importable matplotlib that dies with
# "numpy.core.multiarray failed to import" the first time a chart is drawn.
#
# The sidecar's numpy usage is ndarray/random/log/sqrt/exp/euler_gamma, all
# unchanged between 1.26 and 2.x, so the cap costs nothing functionally. Note
# it does mean the frozen sidecar runs numpy 1.26 while the 64-bit test venv
# (requirements.txt) runs 2.x — worth keeping in mind when a failure smells
# numeric.
#
# Use requirements.txt for the 64-bit dev/test venv (full deps, runs all
# pytest including LHS + report tests).
# NOTE: releases install from requirements-sidecar.lock (fully pinned), not
# this file. This file states intent and constraints; after changing it,
# regenerate the lock (procedure in the lock's header) — otherwise the
# change silently never ships.
#
# ── Why uvicorn has no [standard] extra and kiwisolver is pinned ─────────────
# Everything here must install from win32 cp310 *wheels*: the GitHub runner
# can't link x86 C extensions (kiwisolver 1.5.0's build died with
# LNK2001 __except_handler4 in the rc.13 release run).
#   * uvicorn's [standard] extra pulls httptools, which has no win32 wheel
#     for any version. The sidecar serves plain HTTP on localhost — uvicorn's
#     h11 fallback covers that, and its auto-protocol modules import fine
#     with the extras absent. websockets/watchfiles are equally unused.
#   * kiwisolver (via matplotlib) dropped win32 wheels after 1.4.7.

pyyaml>=6.0
numpy>=1.24,<2
fastapi>=0.115
uvicorn>=0.34
python-multipart>=0.0.9
matplotlib==3.7.5
